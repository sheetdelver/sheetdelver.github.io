Open source · Foundry VTT companion

Character sheets
outside Foundry

SheetDelver puts each player's Foundry VTT character sheet on their own phone, tablet, or PC for in-person play, with dice, chat, shared journals, and combat close at hand.

See it in play ↓ Set it up ↓

Works with Foundry VTT 13 & 14

01 / At the table

Everything the
table reaches for

The GM runs the world in Foundry. Each player keeps their sheet in hand, and rolls, messages, and handouts arrive in real time.

Dice that land together

Roll from the sheet or the dice tray. Optional 3D dice play out the recorded result for everyone at the table.

Chat and roll cards

Message the GM and the table, read results on clear roll cards, and choose which notifications you see.

Shared moments

Images and journals the GM shows to players open right away, with a journal browser for the details.

Combat at a glance

When a fight starts, the tracker shows whose turn it is. Roll initiative and end your turn from your device.

  • Light and dark themes
  • 3D dice appearance settings
  • Touch-friendly layouts
  • Player list and connection status

03 / For the GM

Run the table
your way

Your world stays in Foundry. SheetDelver adds tools for running in-person encounters and looking after the server.

04 / FAQ

Made for
the table

A few answers about how SheetDelver fits into an in-person game.

What is SheetDelver for?

It gives players at an in-person table a browser view of their Foundry VTT character sheets and shared table tools. The GM continues to run the world in Foundry.

Do I need plugins or add-ons?

No. GMs don’t need to install or manage any Foundry modules for SheetDelver. Players open SheetDelver in a browser on their own device and sign in with their Foundry user, but never connect to the GM’s Foundry instance themselves; SheetDelver handles that connection.

Which devices can players use?

The interface is designed for phones, tablets, and PCs. Players need a browser and access to the SheetDelver server.

What comes with the sheets?

Chat, a dice roller with optional 3D animations, shared images and journals, and combat context are available in the player view.

Where does SheetDelver run?

On any computer you control that can reach your Foundry server; it doesn’t need to be the same machine. It runs on Node.js, and players open it from their browsers. Importing worlds directly also needs access to Foundry’s data directory or the world’s files.

Do I need to change my Foundry world?

No Foundry module is needed. SheetDelver connects over Foundry’s own socket connection. The GM sets up a Foundry user for SheetDelver to connect with, and players sign in with their own Foundry users.

05 / Getting started

Set it up
locally

For now, use the repository's setup wizard and manual instructions.

BEFORE YOU BEGIN

Node.js 22.12+ · Foundry VTT 13 or 14 · access to a Foundry world

01

Get the source

Clone the project and install its dependencies.

git clone https://github.com/sheetdelver/sheetdelver.gitcd sheetdelver && npm install
02

Configure your connection

Run the setup wizard, then provide the Foundry service account values through environment variables or an owner-only .env file.

npm run setup
03

Start SheetDelver

Start the development server to try it out. It prints separate local admin and player URLs. For regular games, build and run the production server instead.

npm run devnpm run build && npm start
04

Create your admin account

Open the local admin URL and use the one-time credential from setup, valid for 60 minutes, to create your account. Then open the player URL when you're ready.
